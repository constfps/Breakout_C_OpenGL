<h1>Breakout! C + OpenGl Version</h1>
<h4>A small file size implementation of the arcade game breakout using C and Glut (OpenGl Utility Toolkit).</h4>
<h4>Works for both Linux with some resolution issues in windows. Compile using the `make` command. Will need to have miniaudio.h in same dir as main.cpp</h4>
